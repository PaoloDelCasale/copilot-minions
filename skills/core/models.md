# Model routing

Model routing is platform-specific. The installer replaces this shared placeholder
with the selected platform overlay's `models.md`; do not infer one provider's route
from another provider's matrix.

Every spawn pins both model and reasoning effort. A user-requested model overrides
the matrix only for that batch. Record the expected and actual route in board Notes,
and treat a mismatch as a protocol error rather than falling back to another model
or provider.
